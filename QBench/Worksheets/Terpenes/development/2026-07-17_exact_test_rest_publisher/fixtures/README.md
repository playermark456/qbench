# Fixtures

The unit tests generate synthetic Batch and Test records in memory. All IDs,
hashes, analyte values, filenames, assay names, reviewer identifiers, and
worksheet objects are task-only synthetic values.

No customer data, Sandbox token, session credential, signed URL, raw Sandbox
identifier, production identifier, or API response is stored here.

`sanitized_audit_example.json` shows the evidence shape without any raw entity
identifier.
