# AIT Feed DDGs

This is the AIT Feed DDGs laboratory-planning project. Scenario B - the GAFTA-strict, lower-capital configuration - is the current planning priority.

SmartDraw is the editable layout source. The repository contains planning, reference, procurement, and audit files; it does not contain construction documents. Field, architect, MEP, safety, and OEM verification are still required before design or construction decisions are made.

## Start here

1. Read `PROJECT_STATUS.md` for the current state and exact next prompt.
2. Read `FILE_MANIFEST.md` for source provenance and hashes.
3. Open `drawings/smartdraw/source/AIT_DDGS_Future_Space_Editable_Exact_Scale.sdr` in SmartDraw.
4. Use the annotated plan and reference-on exports when checking the base plan.
5. Use `data/instrument-options/DDGS_instrument_options_GAFTA_strict_v3.xlsx` for Scenario B equipment selection and site requirements.

## Important limitations

- Preserve the drawing scale of 1/8 inch = 1 foot.
- Keep all SmartDraw tables, equipment, instruments, computers, utilities, clearance envelopes, and labels individually movable.
- Do not treat any planning drawing here as construction-ready.
- Do not add credentials or authenticated SmartDraw links.
