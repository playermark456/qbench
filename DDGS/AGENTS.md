# Instructions for Future Codex Work

1. Read `PROJECT_STATUS.md`, `README.md`, `FILE_MANIFEST.md`, and `CHANGELOG.md` first.
2. Verify the active Git branch is exactly `AIT-Feed-DDGs` before changing files.
3. Preserve original references and work only on clearly versioned copies.
4. Keep SmartDraw tables, equipment, instruments, computers, utilities, labels, and clearance envelopes individually movable.
5. Preserve the exact architectural scale of 1/8 inch = 1 foot and recheck the 20-foot reference ruler after major edits.
6. Never commit credentials or authenticated SmartDraw links.
7. Update `PROJECT_STATUS.md` and `CHANGELOG.md` after each meaningful task.
8. Export SDR, reference-on PDF, native-only PDF, SVG, and PNG audit files after major SmartDraw milestones.
9. Never describe the planning drawing as construction-ready without the required field, architect, MEP, safety, and OEM verification.
